# TwinTeem

Apple-style панель для контроля команды 3D-моделлеров и проектов цифровых двойников.

## Реализовано

- KPI и четыре редактируемые карточки сотрудников;
- проекты, адреса, база назначения, статусы и заметки;
- четыре этапа и автоматически рассчитанный общий прогресс;
- календарь истории и аналитика на Recharts;
- адаптивный интерфейс для Mac, iPad и iPhone;
- сохранение изменений в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Production-проверка: `npm run build`.
