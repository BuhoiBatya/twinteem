# TwinTeem

Apple-style панель для контроля команды 3D-моделлеров и проектов цифровых двойников.

## Реализовано

- KPI и редактируемые карточки сотрудников;
- проекты, адреса, база назначения, статусы и заметки;
- индивидуальные этапы и автоматически рассчитанный общий прогресс;
- ежедневные серверные снимки, календарь истории и аналитика на Recharts;
- индивидуальная дневная норма и KPI по формуле «фактический прирост / норма»;
- фильтры аналитики за 7, 30 и 90 дней, темп, KPI и вклад сотрудников;
- адаптивный интерфейс для Mac, iPad и iPhone;
- локальный кэш для работы при временном отсутствии сети;
- серверная авторизация администратора и гостевой режим «только чтение»;
- добавление и редактирование сотрудников, загрузка и сжатие аватаров;
- PDF-отчёт с реальными KPI, графиками и детализацией по каждому сотруднику;
- серверная синхронизация сотрудников через Neon/PostgreSQL;
- экспорт и восстановление JSON-бэкапа;
- произвольное количество индивидуальных этапов у каждого сотрудника.

## Авторизация

Скопируйте `.env.example` в `.env.local` и задайте собственные значения. Для Vercel добавьте эти же три переменные в **Settings → Environment Variables**:

- `ADMIN_LOGIN` — логин администратора;
- `ADMIN_PASSWORD` — пароль администратора;
- `AUTH_SECRET` — случайная секретная строка длиной от 32 символов.
- `DATABASE_URL` — строка подключения Neon/PostgreSQL.

Без этих переменных административный вход в production намеренно отключён. Гостевой просмотр остаётся доступным.

## Серверное хранение

В Vercel откройте **Storage → Create Database → Neon**, подключите базу к проекту для Production и Preview и выполните Redeploy. Интеграция добавит `DATABASE_URL` автоматически. Таблицы текущего состояния и ежедневной истории создаются приложением при первом обращении. Один снимок на дату автоматически обновляется при сохранении. До подключения базы приложение продолжает использовать локальный кэш браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Production-проверка: `npm run build`.
